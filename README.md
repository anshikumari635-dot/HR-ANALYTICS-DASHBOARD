# 📊 HR Analytics Dashboard | Excel Project

## 📌 Project Overview
The **HR Analytics Dashboard** is a data analysis project developed using Microsoft Excel to analyze employee information, monitor workforce trends, and understand employee attrition. The dashboard presents important HR metrics through interactive visualizations and summary KPIs, helping users explore workforce data and support data-driven decision-making.

## 🎯 Project Objectives
- Analyze employee attrition and retention patterns.
- Monitor active employees and total employee count.
- Understand workforce demographics, including age and gender.
- Explore attrition across departments, job roles, and other employee categories.
- Present HR insights in a clear, professional, and visually appealing dashboard.

## 🛠️ Tools & Technologies
- **Microsoft Excel** – Data analysis and dashboard creation
- **Pivot Tables** – Data summarization and analysis
- **Charts & Visualizations** – HR trend analysis
- **Excel Formulas** – KPI calculations and reporting

## 📈 Key Performance Indicators (KPIs)
The dashboard highlights the following metrics:

- **Total Employees:** 1,470
- **Attrition Count:** 237
- **Active Employees:** 1,233
- **Attrition Rate:** 16.12%
- **Average Employee Age:** Approximately 37 years

## 📊 Dashboard Features
- Department-wise attrition analysis
- Employee demographics and age distribution
- Job role and workforce analysis
- Employee attrition and retention metrics
- KPI cards for quick performance monitoring
- Visual reports for better understanding of HR data
